# 第三方声明

## o-pi

[o-pi](https://github.com/Orion-zhen/o-pi) 是 Orion-zhen 维护的项目，提供 `opi-web` 后端和原生网页。opi-hub 是独立维护的第三方项目。感谢 o-pi 的作者和贡献者。

opi-hub 源码和分发包不包含 o-pi 源码或 `opi-web` 可执行文件。用户从上游获取 `opi-web` 后，节点在设备上启动该程序。中心通过节点转发原生页面和请求，审批规则及最终校验由设备上的 o-pi 负责。获取方式见[安装与启动](installation.md#获取-opi-web)。
