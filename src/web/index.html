    会话与历史

    每次运行新建专用会话，仍遵循原审批规则。离线或错过不补跑，上次未结束或结果未知时不重入。暂停只影响未来触发，不停止当前运行。

    计划

    运行记录

    进行中与待核对记录优先显示，历史按触发日期分组，保留最近 50 次记录。已结束仅表示执行结束，不代表内容已验证成功。

    从第一台设备开始

    添加设备并运行连接程序，即可在这里打开它的原生 o-pi 界面。

    文件、模型凭据和运行环境留在设备上。中心负责连接与转发。

    新建计划任务

    选择设备后显示可用模型，仅影响本计划的新会话。

    结束早于开始表示跨至次日，开始与结束不能相同。

    以窗口开始为基准，每隔指定的实际分钟数触发。包含开始、不包含结束，窗口结束不停止已运行任务。每次都会新建会话，可能产生模型费用。

    执行星期

    中心需保持运行。每台设备最多一个计划运行，包含等待审批的时间。计划和任务描述会保存到中心数据库，可为计划指定模型，不修改设备默认配置。指定模型不可用时运行失败，不自动换模型。

    确认计划操作

    新建会话

    在目标设备的已有目录创建全新会话，不切换其他页面。

    目录来自目标设备。可输入完整路径切换磁盘，不会自动创建文件夹。

    创建时若需信任项目，请在“消息中心 → 待处理”回答。完成后可从创建记录打开原生会话。关闭弹窗或刷新页面不会撤销已经提交的创建。

    添加设备

    为设备创建独立凭据，之后在该设备运行连接程序。

    在目标设备保存为 node.json：

    凭据仅在此处显示一次。请勿分享，并限制配置文件的读取权限。

    1. 在目标设备安装 opi-web，无需手动打开。
    2. 将 command 改为程序完整路径，例如 ["F:/apps/opi-web.exe"]。节点会自动后台启动它。
    3. 在 opi-hub 项目目录运行：
      bun run node --config /path/to/node.json

    重启托管后端？

    这会中断该设备上的所有托管任务，取消未完成交互。只重启节点自己启动的 opi-web，不影响其他独立进程。已有任务不会自动重发，只有已保存的历史可重新打开。

    移除设备？

    撤销凭据并关闭节点托管的后端，会中断该设备上的托管任务。不会删除已保存的会话文件，也不关闭其他独立进程。
